Objective

Build a simple, welcoming Academy section for Cyber Grad Chronicles that helps beginners learn cybersecurity one clear lesson at a time.

Goals

Show the existing Academy modules in a clear list: Cybersecurity 101, Cyber Awareness Essentials, Threats, Defense, Cloud, Governance, Careers, and Certifications.

Let a visitor open any published module and move between its lessons in no more than two clicks from the Academy page.

Give every lesson a title, a short introduction, readable sections, and one practical takeaway.

Make the Academy usable on phone and desktop, with working navigation and accessible text contrast.

Keep the site building successfully and existing pages working after each change.

Working rules

Choose the simplest solution that meets the goal. Do not add a framework, database, login, AI feature, or new dependency unless the task truly needs it.

Reuse the site's current components, styles, routes, and black-and-gold visual language.

Build one small, testable change at a time. Keep code readable and avoid abstraction for a single use.

If lesson content is missing, use a clearly labeled draft or placeholder; do not invent credentials, claims, or citations.

After editing, run the project's existing build or check command and fix any errors you introduced.
